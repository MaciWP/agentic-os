# Design system

Extracted from the code. Code wins: when this file and the code disagree, follow the
code and fix this file. Source of truth for values: `web/tokens.css`.

Character: Linear-like with colour. Quiet cool neutrals (hue 270), one accent,
dense 13px UI; each harness has its own hue, and raised surfaces carry a soft shadow.
UI copy is Spanish (es-ES).

## Tokens

Colors are OKLCH, defined once on `:root` in `web/tokens.css`. The app is dark only
(`color-scheme: dark`). Tailwind names them through
`@theme inline`: `bg-bg`, `text-ink`, `border-line`… shadcn's semantic names point at the same
tokens. **The brand accent is `primary` in utilities** (`bg-primary`, `text-primary`,
`ring-primary`); `bg-accent` is shadcn's quiet hover fill (`--hover`). The raw token keeps its
name, `--accent`.

| Token | Value | Role |
|---|---|---|
| `--bg` | `oklch(0.165 0.007 60)` | Page background, sticky heads |
| `--panel` | `oklch(0.205 0.008 60)` | Raised surfaces, buttons, editors |
| `--ink` | `oklch(0.94 0.004 270)` | Primary text |
| `--ink-2` | `oklch(0.7 0.012 70)` | Secondary text, counts, empty states |
| `--line` | `oklch(0.29 0.009 60)` | Borders, dividers, skeletons |
| `--accent` | `oklch(0.7 0.15 275)` | Primary action, focus ring, links. Follows the active Mesa's work block on every page (`useBlockAccent` sets `data-accent="<color>"` on `<html>` → `--blk-<color>`, and `--selected` becomes the accent at 20 % over `--bg`); a Mesa with no block keeps this violet |
| `--on-accent` | `oklch(0.165 0.007 60)` | Text on an accent fill (`.btn-primary`, `.btn-danger`) |
| `--ok` | `oklch(0.72 0.14 155)` | Running, success |

The harness hues share L 0.62: the 8px dot measures
at least 3.29:1 against the panel and the terminal header, and
the chip's text (`--ink` or white on a 16 % tint) at least 11.48:1. The colour never
carries meaning alone: the chip shows the harness name, and where a logo stands for it (the
tree's terminal rows, the top bar) the name is in `title` and the row's accessible name.

fixed palette outside the tokens, for xterm (`THEME`) and for its chrome:

Jira issue icons (`web/features/tickets/icons.tsx`) use `--accent` and `--bad`,
plus `oklch(0.6 0.17 300)` for epics.

## Type scale

Families (`web/tokens.css`): sans `"IBM Plex Sans Variable", ui-sans-serif, system-ui,
-apple-system, sans-serif`, self-hosted from `@fontsource-variable/ibm-plex-sans` (imported in
`web/main.tsx`, bundled by Vite, so the CSP's `default-src 'self'` admits it); mono
`ui-monospace, "SF Mono", Menlo, monospace` for xterm and Monaco.

| Size | Carrier | Use |
|---|---|---|
| 20px | `text-[20px] font-semibold` | Ticket title (`features/tickets/detail.tsx`, plus `leading-7`), Notas title (`features/memory/desk-rail.tsx`, `desk.tsx`) |
| 16px / 14px | `.adf h2` / `.adf h3-h6` | Jira description headings |
| 13px | `body` (`web/tokens.css`), `text-[13px]` | Base UI text, editors, terminal (`fontSize: 13`) |
| 12px | `text-[12px]`, `.btn`, `.group-head`, `.section-title` | Secondary text, buttons, mono detail |
| 11px | `text-[11px]`, `.pill` | Counts, pills, meta |

Weights: 500 (`font-medium`, buttons, nav, group heads), 600 (`font-semibold`, titles,
`.section-title`). `.section-title` is 12px, uppercase, `letter-spacing: 0.04em`, `--ink-2`.
Counts use `tabular-nums`.

## Spacing

Tailwind's 4px scale. Common: `px-4` (16px, the row and block gutter), `gap-2`,
`px-2`, `px-3`, `py-2`, `py-1.5`, `gap-3`, `mt-1`/`mt-2`/`mt-3`.

Fixed component heights (`web/tokens.css`): row 36px, group head 32px, nav item 28px,
button 26px, ghost button 24px, pill 20px. Block header `h-9` (36px) (`web/ui.tsx`).

## Usage rules

- Colors only through tokens on every page except the terminal window, which keeps its
  own dark palette (above). Other raw colors: the logo's gradient and white mark
  (`.brand-mark`, and the favicon in hex: a data URL sees no CSS variables) and the epic icon.
- A harness colour reaches the page only through `data-harness` (`HarnessDot`,
  `HarnessChip`, `.tile`); it identifies, it never signals state.
- Status is color plus a word, never color alone: state dots carry a label
  (`features/terminals/panel.tsx` `STATE`), alerts carry a title.
- Motion is `motion-safe:` and never loops for long: an endless animation costs a compositor
  frame every vsync while it shows. A status that asks for the eye pulses three times
  (`animate-attention`, `web/tokens.css`) and stays lit; only a short wait (a skeleton, a
  spinner) may loop. An agent's working icon turns 45° eight times a second on one shared timer
  (`spinRef`, `web/motion.ts`), so every spinner steps in the same frame; measured in
  `e2e/ui-motion-perf.e2e.ts`.
- Hover changes colour only: `.row`, `.btn`, `.btn-ghost`, `.nav-item` and the shadcn `Button`
  and `Tabs` ease color, background, border and filter over 120 ms; never `transition: all`.
  Under `prefers-reduced-motion: reduce` every animation and transition runs for 1 ms, once.
- Native scrollbars (`.overflow-auto`, `.overflow-y-auto`, `.overflow-x-auto`, `.option-list`)
  are thin, with a transparent thumb that takes `--scroll-thumb` (3:1 on the background) while
  the pointer is over the box or it has keyboard focus. xterm and Monaco draw their own.
- Menus (`components/ui/dropdown-menu.tsx`): as wide as their longest item (`min-w-44`,
  `max-w-80`), `28px` rows of 13px text, a 14px `--ink-2` icon first, `DropdownMenuShortcut`
  for the key at the end, `variant="destructive"` for the item that ends something, last and
  after a separator; they fade in over 100 ms, no zoom or slide.
- Tinted surfaces use the status token at low alpha with a matching border:
  `bg-bad/5 border-bad/40`, `bg-warn/10 border-warn/50`, `bg-primary/5 border-primary/40`.
- Every data panel renders the same three non-data states: `SkeletonRows` while
  loading, `ErrorState` with retry on error, `DisabledState` when the provider is off
  (for example `features/tickets/page.tsx`, `features/tickets/detail.tsx`,
  `features/prs/panel.tsx`).
- Empty states are one `--ink-2` sentence that says why it is empty and where to change
  it (`features/prs/panel.tsx`, `features/tickets/detail.tsx`,
  `features/projects/tree.tsx`).
- Same-named controls in a tree carry the node's full label in `aria-label`
  (`Abrir una terminal en env/dir`, `Parar Claude en env-a/backend`), so a screen
  reader and a test can tell them apart.
- At most one `.btn-primary` per view; the rest are `.btn` or
  `.btn-ghost`.
- Monospace (`font-mono`) for ids, paths, error detail and editors, never for prose.
- A failed refetch with data still shown is `StaleNotice` above that data, never a red line
  beside it and never an empty list; a read that never succeeded is `ErrorState`.
- A local error is `InlineError`, never a hand-made `role="alert"` with `text-bad`.
- Text cut by `truncate` or `line-clamp` carries the full text in `title` (its own or the
  row's). `e2e/clip.e2e.ts` fails on a cut whose title does not hold every word of it.
- Supported widths: 800 px and up on the desktop, and 412 px on the phone. From `md` a page
  shows all its columns; below `md` a list-and-detail page (Tickets, Notas) shows one at a
  time, the list or the open item with a `← <page>` link in `md:hidden`, and Notas hides its
  filter rail. Below `md` a cut that matters wraps instead: a phone has no hover for a
  title. `e2e/clip.e2e.ts` measures Inicio, Tickets, Agentes, Consumo, Notas and an open
  note at 412, 800, 1024 and 1280.
